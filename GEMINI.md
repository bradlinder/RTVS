# AI Studio Project Instructions

## App Purpose & Web Preview Requirement
- **AI Studio Web Preview Directive**: The AI Studio web preview for this project MUST always display the **interactive changelog and release history viewer** (`CHANGELOG.md`).
- **Do Not Replace**: Under no circumstances should the web frontend (`/src/App.tsx`) be replaced with placeholder landing pages, dummy audio/video players, or temporary test widgets unless explicitly requested by the user.
- **Changelog Synchronization**: Whenever `CHANGELOG.md` or version information is updated in the desktop application codebase, ensure the changes are reflected in the changelog viewer in `/src/App.tsx`.
