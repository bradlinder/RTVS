Radio & TV Segmenter v2.2 Build Notes

Windows builds now produce two frozen executables: the main GUI and a dedicated
workers\prs_worker.exe AI worker. The build also runs PyTorch/torch._C,
CTranslate2, Transformers and Silero VAD smoke tests in both frozen runtimes.
If any test fails, no installer should be generated.

===============================================================================
Radio & TV Story Segmenter - Build & Environment Setup Instructions
===============================================================================

1. SYSTEM PREREQUISITES
-------------------------------------------------------------------------------
- Python 3.10 to 3.12 (64-bit recommended)
- Node.js 18+ and npm (required for building web preview assets)
- FFmpeg installed and accessible in your system PATH (or in the app root directory)
- Git

2. HARDWARE ACCELERATION (NVIDIA CUDA - WINDOWS)
-------------------------------------------------------------------------------
The core application is CPU-first across all operating systems. On Windows
systems with an NVIDIA GPU, an isolated CUDA environment can be downloaded
on demand directly from Settings > GPU Acceleration (NVIDIA CUDA)...
No manual PyTorch or CUDA driver installation is required in the base environment.

3. PYTHON VIRTUAL ENVIRONMENT & DEPENDENCIES
-------------------------------------------------------------------------------
Create and activate your virtual environment:

  Windows:
    python -m venv venv
    venv\Scripts\activate

  Linux / macOS:
    python3 -m venv venv
    source venv/bin/activate

Install core application requirements:
    pip install -r requirements.txt
    pip install -r requirements-build.txt

Heavy machine translation (OPUS-MT / Transformers) runs in an isolated,
on-demand runtime managed automatically by the application (see plugins/translation).

4. BUILDING FRONTEND ASSETS (Vite + React)
-------------------------------------------------------------------------------
If working with web/transcript preview components:
    npm install
    npm run build

This outputs bundled assets into the distribution web root.

5. RUNNING THE APPLICATION LOCALLY
-------------------------------------------------------------------------------
Execute:
    python RadioTVSegmenter.py

6. PACKAGING, STANDALONE BUILDS & RELEASE DISTRIBUTION
-------------------------------------------------------------------------------
- Windows:
    Run build_windows.bat or compile RadioTVStorySegmenter.iss using Inno Setup.
- macOS:
    Run ./build_macos.sh
- Linux:
    Run ./build_linux.sh or ./installer/Linux/build_deb.sh

Note on Releases:
Distribute all built installers, binaries, and source snapshot archives via
GitHub Releases. Avoid committing .zip or archive files directly into git history
to prevent repository bloat.
