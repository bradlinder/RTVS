Radio & TV Segmenter v2.1.5 Build Notes

Windows builds now produce two frozen executables: the main GUI and a dedicated
workers\prs_worker.exe AI worker. The build also runs PyTorch/torch._C,
CTranslate2, Transformers and Silero VAD smoke tests in both frozen runtimes.
If any test fails, no installer should be generated.

===============================================================================
Radio & TV Story Segmenter - Build & Environment Setup Instructions
===============================================================================

1. SYSTEM PREREQUISITES
-------------------------------------------------------------------------------
- Python 3.10 to 3.12 (64-bit recommended)
- Node.js 18+ and npm (required for building web preview assets)
- FFmpeg installed and accessible in your system PATH (or in the app root directory)
- Git

2. HARDWARE ACCELERATION DRIVERS
-------------------------------------------------------------------------------
- NVIDIA: CUDA 11.8 or 12.x Toolkit + cuDNN
- AMD / Intel (Windows): ONNX Runtime DirectML backend is supported for direct
  hardware acceleration across Radeon GPUs and APUs (e.g. Ryzen AI).
- Apple Silicon: PyTorch MPS acceleration supported natively on macOS.

3. PYTHON VIRTUAL ENVIRONMENT & DEPENDENCIES
-------------------------------------------------------------------------------
Create and activate your virtual environment:

  Windows:
    python -m venv venv
    venv\Scripts\activate

  Linux / macOS:
    python3 -m venv venv
    source venv/bin/activate

Install core requirements:
    pip install -r requirements.txt
    pip install -r requirements-build.txt

For DirectML GPU acceleration on Windows:
    pip install onnxruntime-directml

For Pyannote Diarization & MarianMT Translation:
    pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121  # or cpu / directml
    pip install pyannote.audio transformers sentencepiece sacremoses

4. BUILDING FRONTEND ASSETS (Vite + React)
-------------------------------------------------------------------------------
If working with web/transcript preview components:
    npm install
    npm run build

This outputs bundled assets into the distribution web root.

5. RUNNING THE APPLICATION LOCALLY
-------------------------------------------------------------------------------
Execute:
    python RadioTVSegmenter.py

6. PACKAGING / STANDALONE BUILDS
-------------------------------------------------------------------------------
- Windows:
    Run build_windows.bat or compile RadioTVStorySegmenter.iss using Inno Setup.
- macOS:
    Run ./build_macos.sh
- Linux:
    Run ./build_linux.sh or ./installer/Linux/build_deb.sh
